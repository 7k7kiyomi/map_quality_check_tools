## ID 注意事项

- **204 被复用**：“字体斜体”和“字距”在算法实现中都使用 204；示例 XML 也把“字距”设为 204。因此，51 是质检项名称数，50 是唯一 ID 数。
- “字距”的正常执行路径写入 204，但在缺少实际注记图层的提前返回路径中写入 **203**，与“字体颜色”相同。这是当前源码中的不一致，不能把 203 当作“字距”的正式 ID。
- “字体斜体”函数前的注释写着 **`205 - 注记斜体检查`**，但函数实际把 `result.id` 设为 **204**，且算法标记为暂未实现。因此本表按当前运行代码记录为 204；**205 是注释中的预期编号，尚未成为运行时 ID**。

- 主任务管理器算法注册：[`map_check_task_manager.cpp`](map_check_task_manager.cpp) 中的 `initAlgorithmMap()`。

- 502 独立入口：[`SeriesCrossScaleExpressionTaskDialog.cpp`](SeriesCrossScaleExpressionTaskDialog.cpp) 中的 `kCrossScaleCheckItemId`。
- 字距示例配置：[`annotation_rule_examples/省级表面注记_标注.xml`](annotation_rule_examples/省级表面注记_标注.xml)。
